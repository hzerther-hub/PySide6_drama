# Guide de copywriting promotionnel pour drames courts

## Principes universels

- Tout part de « l'accroche conflictuelle » : ouvrez sur la contradiction / le retournement le plus fort, sans pose de décor préalable
- Les trois questions d'extraction des arguments : quel est le plus grand moment de gratification de cette histoire ? à qui le public s'identifie-t-il ? quelle réplique accroche le plus ?
- Une copie ne pousse qu'un seul argument de vente central ; les autres arguments attendront d'autres versions
- Ne spoilez pas les retournements clés ; le clickbait a une limite — l'accroche doit pouvoir être tenue par le contenu

## Écriture par plateforme

| Plateforme | Format | Points clés |
|---|---|---|
| Douyin / Kuaishou | script de voix off / sous-titres, 15-45 secondes | Accroche dans les 3 premières secondes (question de suspense / description d'une image de conflit) ; milieu de parcours à rythme rapide qui empile les conflits ; fin qui invite à « toucher la collection pour voir tous les épisodes » |
| Xiaohongshu (RedNote) | note de 200-400 mots | Titre avec étiquette émotionnelle ; corps en langage parlé façon recommandation + temps forts épisode par épisode ; 3-5 hashtags de fin |
| Compte officiel WeChat | article de fond de 500-800 mots | Titre mis en suspens ; sous-titres qui déroulent « personnage - retournement - gratification » ; avertissement de spoilers ; fin qui invite à mettre en favori et suivre les mises à jour |
| Bilibili | titre + description | Titre qui joue avec les mèmes tout en restant limpide ; la description présente les temps forts et le rythme de mise à jour |

## Format de sortie (versions multiples)

Produisez en une seule sortie au moins 3 versions, chacune utilisable de façon autonome :
1. **Version suspense** : ouvrez sur l'énigme non résolue, ne dévoilez pas le dénouement
2. **Version émotion** : ouvrez sur le conflit affectif le plus résonnant (par ex. « Dix ans plus tard il est de retour, et tous attendent de le voir tomber »)
3. **Version bénéfices** : liste directe des moments de gratification (giffles retentissantes / ascension de l'outsider / romance sucrée), étiquetée « forte densité de gratification »

Structure de chaque version : accroche (1-2 phrases) → développement des arguments (3-5 phrases) → CTA (1 phrase : toucher la collection / suivre / mettre en favori).

## Lignes rouges de langue

- N'enjolivez pas une intrigue qui n'existe pas ; pas de formulations vulgaires, provocatrices ou dévalorisantes
- Aucune allusion aux marques ou aux personnalités réelles
- CTA concret et précis : si vous dites « touchez la collection », ne dites pas seulement « venez voir »
