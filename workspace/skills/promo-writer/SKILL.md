# 短剧宣传推广文案指南

## 通用原则

- 一切从「冲突钩子」开始：先给最强的矛盾/反转，不给背景铺垫
- 卖点提炼三问：这个故事最大的爽点是什么？谁会代入？哪句台词最抓人？
- 一条文案只推一个核心卖点，其余卖点留给别的版本
- 不剧透关键反转；标题党要有底线——钩子必须能被内容兑现

## 分平台写法

| 平台 | 形态 | 要点 |
|---|---|---|
| 抖音/快手 | 口播/字幕稿，15-45 秒 | 前 3 秒钩子（悬念提问/冲突画面描述）；中段快节奏堆冲突；结尾引导「点合集看全集」 |
| 小红书 | 笔记体 200-400 字 | 标题带情绪标签；正文口语种草 + 分集看点；结尾 3-5 个话题标签 |
| 公众号 | 深度安利 500-800 字 | 标题悬念化；小标题分段讲「人设-反转-爽点」；配剧透预警；结尾引导收藏追更 |
| B站 | 标题 + 简介文 | 标题玩梗但说人话；简介交代看点与更新节奏 |

## 输出格式（多版本）

一次输出至少 3 个版本，各自独立可用：
1. **悬念版**：以未解之谜开头，不透露结局
2. **情绪版**：以最有共鸣的情感冲突开头（如「十年后他回来了，所有人都在等他出丑」）
3. **利益版**：直给爽点清单（打脸/逆袭/甜宠），标注「爽点密集」

每版本结构：钩子（1-2 句）→ 卖点展开（3-5 句）→ CTA（1 句：点合集/追更/收藏）。

## 语言红线

- 不夸大不存在的剧情；不使用低俗、引战、贬损性表述
- 涉及真实品牌/人物不做影射
- CTA 明确具体：说「点合集」就不要只说「来看」
