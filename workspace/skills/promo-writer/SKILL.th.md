# คู่มือการเขียนสำเนาโปรโมทละครสั้น

## หลักการสากล

- ทุกอย่างเริ่มต้นจากฮุกความขัดแย้ง: เปิดด้วยความขัดแย้ง/การพลิกปมที่รุนแรงที่สุด ไม่ต้องมีการปูพื้นเรื่องเบื้องหลัง
- สามคำถามในการสกัดจุดขาย: จุดมันส์ที่สุดของเรื่องนี้คืออะไร? ใครจะเอ่อเข้าไปเสมือนอยู่ในเรื่อง? บทพูดประโยคไหนโดนใจที่สุด?
- สำเนาหนึ่งชิ้นผลักดันจุดขายหลักเพียงจุดเดียวเท่านั้น จุดขายที่เหลือเก็บไว้ให้ฉบับอื่น
- ไม่สปอยล์การพลิกปมสำคัญ; หัวเรื่องเรียกน้ำย่อยต้องมีขีดจำกัด — ฮุกต้องเป็นสิ่งที่เนื้อหาไปถึงจริงได้

## วิธีเขียนแยกตามแพลตฟอร์ม

| แพลตฟอร์ม | รูปแบบ | หัวใจสำคัญ |
|---|---|---|
| TikTok/Kuaishou | สคริปต์เสียงบรรยาย/คำบรรยายบนจอ 15-45 วินาที | ฮุกใน 3 วินาทีแรก (คำถามกระตุ้นความลุ้น/บรรยายภาพความขัดแย้ง); ช่วงกลางเร่งจังหวะกองความขัดแย้งต่อเนื่อง; ท้ายเรื่องชวนให้ 「กดคอลเลกชันดูครบทุกตอน」 |
| Xiaohongshu (RedNote) | โน้ตสไตล์บทความสั้น 200-400 คำ | หัวเรื่องติดแท็กอารมณ์; เนื้อหาแนะนำแบบปากเปล่าเป็นกันเอง + จุดน่าดูรายตอน; ท้ายด้วยแฮชแท็ก 3-5 อัน |
| WeChat Official Account | บทแนะนำเชิงลึก 500-800 คำ | หัวเรื่องเต็มเปี่ยมด้วยความลุ้น; ใช้หัวข้อย่อยเล่าเป็นช่วง 「ตัวละคร-พลิกปม-จุดมันส์」; ใส่คำเตือนสปอยล์; ท้ายชวนให้บันทึกและติดตามอ่านต่อ |
| Bilibili | หัวเรื่อง + คำอธิบาย | หัวเรื่องเล่นมีมแต่พูดให้คนเข้าใจง่าย; คำอธิบายบอกจุดน่าดูและจังหวะการอัปเดต |

## รูปแบบผลลัพธ์ (หลายฉบับ)

หนึ่งครั้งส่งออกอย่างน้อย 3 ฉบับ แต่ละฉบับใช้งานได้อย่างอิสระ:
1. **ฉบับความลุ้น**: เปิดด้วยปริศนาที่ยังไม่เฉลย ไม่เผยตอนจบ
2. **ฉบับอารมณ์**: เปิดด้วยความขัดแย้งทางอารมณ์ที่คนเข้าถึงได้มากที่สุด (เช่น 「สิบปีต่อมาเขากลับมา ทุกคนกำลังรอดูวันที่เขาต้องอับอาย」)
3. **ฉบับจุดมันส์**: ยกลิสต์จุดมันส์ให้ตรง ๆ (ตบหน้า/พลิกชะตาเฟื้อตัว/โรแมนซ์หวาน) พร้อมป้ายกำกับ 「จุดมันส์ถี่ยบ」

โครงสร้างของแต่ละฉบับ: ฮุก (1-2 ประโยค) → ขยายจุดขาย (3-5 ประโยค) → CTA (1 ประโยค: กดคอลเลกชัน/ติดตาม/บันทึก)

## เส้นแดงด้านภาษา

- ห้ามเกินจริงกับเนื้อเรื่องที่ไม่มีอยู่จริง; ห้ามใช้ถ้อยคำหยาบต่ำ/ยั่วยุทะเลาะ/ดูถูกเหยียดหยาม
- ไม่ทำใบ้ให้เชื่อมโยงไปถึงแบรนด์หรือบุคคลจริง
- CTA ต้องชัดเจนเจาะจง: ถ้าพูดว่า 「กดคอลเลกชัน」 ก็ห้ามพูดแค่ 「มาดูกัน」
