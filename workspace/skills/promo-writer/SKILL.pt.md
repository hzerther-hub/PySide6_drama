# Guia de Copy de Divulgação para Dramas Curtos

## Princípios Universais

- Tudo começa pelo gancho de conflito: abra com a contradição/reviravolta mais forte, sem preparação de contexto
- Três perguntas para destilar pontos de venda: qual é o maior payoff da história? com quem o público vai se identificar? qual fala agarra mais forte?
- Cada texto empurra um único ponto de venda central; os demais ficam para outras versões
- Sem spoiler das reviravoltas-chave; clickbait tem um piso — o gancho precisa ser honrado pelo conteúdo

## Formatos por Plataforma

| Plataforma | Formato | Pontos-chave |
|---|---|---|
| Douyin/Kuaishou | roteiro de locução/legendas, 15-45 s | gancho nos primeiros 3 s (pergunta de suspense/descrição de imagem de conflito); meio com empilhamento rápido de conflitos; fecho conduzindo a "abrir a coletânea para ver todos os episódios" |
| Xiaohongshu (RedNote) | formato nota, 200-400 caracteres | título com rótulo emocional; corpo coloquial de recomendação + destaques por episódio; 3-5 hashtags no final |
| Conta Oficial do WeChat | artigo aprofundado de 500-800 caracteres | título com suspense; subtítulos por trechos sobre "personagem — reviravolta — payoff"; aviso de spoiler; fecho conduzindo a salvar e seguir as atualizações |
| Bilibili | título + texto de descrição | título brincalhão mas de linguagem clara; a descrição cobre os destaques e o ritmo de atualização |

## Formato de Saída (múltiplas versões)

Gere pelo menos 3 versões, cada uma utilizável de forma independente:
1. **Versão suspense**: abre com o mistério não resolvido, sem revelar o desfecho
2. **Versão emocional**: abre com o conflito afetivo de maior ressonância (ex.: "Dez anos depois ele voltou, e todos esperam vê-lo se humilhar")
3. **Versão payoff**: lista direta de recompensas (face-slap/ascensão do underdog/romance doce), rotulada de "payoff em sequência"

Estrutura de cada versão: gancho (1-2 frases) → expansão dos pontos de venda (3-5 frases) → CTA (1 frase: abrir coletânea/seguir/salvar).

## Linhas Vermelhas de Linguagem

- Não exagere enredo que não existe; nada de linguagem vulgar, incendiária ou depreciativa
- Nenhuma alusão a marcas ou pessoas reais
- CTA concreto e específico: se diz "abra a coletânea", não basta dizer "venha ver"
