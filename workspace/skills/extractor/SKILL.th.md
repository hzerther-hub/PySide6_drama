# คู่มือการคัดแยกตัวละคร ฉาก และไอเทม

## มาตรฐานการคัดแยกตัวละคร

ฟิลด์ของตัวละครที่คัดแยกได้ (ตรงกันแบบหนึ่งต่อหนึ่งกับพารามิเตอร์ของเครื่องมือ `save_dedup_characters`):
- **name** (บังคับ): ชื่อเต็มของตัวละคร
- **role**: ตำแหน่งบทบาทของตัวละคร — ตัวเอก/ตัวประกอบสำคัญ/ตัวประกอบ
- **appearance**: คำบรรยายลักษณะภายนอก (300-500 ตัวอักษร) — เพศ ความรู้สึกอายุ เค้าหน้า รูปร่าง บุคลิก อย่าแยกนิสัยของตัวละครออกมาเขียนต่างหาก ให้เปลี่ยนเป็นบุคลิกภายนอกและสีหน้า ถักทอเข้าไว้ในคำบรรยายลักษณะภายนอก (เช่น "นิสัยเย็นชา" ควรเขียนเป็น "แววตาเย็นยะเยือก สีหน้ายับยั้ง หัวเราะน้อย")
- **styling**: การจัดลุค — ทรงผม เสื้อผ้า การแต่งหน้า เครื่องประดับ ฯลฯ
- **description**: ประวัติหลังและความสัมพันธ์ของตัวละคร (ส่วนเสริมเพิ่มเติม ไม่บังคับ)

## มาตรฐานการคัดแยกฉาก

ฟิลด์ของฉากที่คัดแยกได้ (ตรงกันแบบหนึ่งต่อหนึ่งกับพารามิเตอร์ของเครื่องมือ `save_dedup_scenes`):
- **location** (บังคับ): ชื่อสถานที่โดยเฉพาะ
- **time**: ช่วงเวลา (เช่น กลางวัน/พลบค่ำ/ดึกดื่น) สถานที่เดียวกันแต่ต่างช่วงเวลาถือว่าเป็นฉากใหม่
- **prompt**: คำบรรยายฉาก — พื้นที่ เครื่องประกอบฉาก บรรยากาศยุคสมัย องค์ประกอบภาพสำคัญ (ฉากล้วน ๆ ไม่มีคน)
- **lighting**: แสงเงาของฉาก — แหล่งกำเนิดแสง โทนสี ความสว่าง-มืด อารมณ์บรรยากาศ

## มาตรฐานการคัดแยกไอเทม

**หลักการสำคัญ: คัดแยกน้อยยังดีกว่าคัดแยกมาก** ไอเทมเป็นทรัพย์สินต้นทุนสูงที่ใช้สร้างภาพสินค้าชิ้นเดียวพื้นหลังขาวล้วน เพื่อให้ช็อตปิดของวิดีโออ้างอิง จึงควรคัดเฉพาะไอเทมที่สำคัญต่อเนื้อเรื่องเท่านั้น หนึ่งตอนโดยทั่วไปมี **0-3 ชิ้น** ของไอเทมสำคัญ หากเกิน 3 ชิ้น ให้จัดอันดับตามความสำคัญต่อเนื้อเรื่องและเก็บไว้เพียง 3 ชิ้นแรก

ต้อง**เป็นไปตามเงื่อนไขทั้งสองข้อต่อไปนี้พร้อมกัน** ขาดข้อใดข้อหนึ่งไม่ได้:
1. **ขับเคลื่อนเนื้อเรื่องโดยตรง**: การปรากฏตัว การส่งต่อ ความเสียหาย หรือการค้นพบของวัตถุชิ้นนี้ทำให้เกิดจุดพลิกผันของเรื่อง (เช่น อาวุธสังหาร ของระลึกคู่รัก เอกสารสำคัญ ของขวัญสารภาพรัก หลักฐานชี้ขาด)
2. **คู่ควรแก่การสร้างภาพแยกเดี่ยว**: สตอรีบอร์ดในเวลาต่อมาจะให้ช็อตปิดกับมันหรือให้มันปรากฏซ้ำ จึงจำเป็นต้องมีลักษณะที่คงที่แน่นอน

**สามคำถามตรวจสอบ** (ถามและตอบกับตัวเองสำหรับไอเทมที่ผ่านเกณฑ์เบื้องต้นแต่ละชิ้น หากคำตอบข้อใดเป็น "ไม่" ให้ละทิ้งทันที):
- ① หากตัดมันออก เนื้อเรื่องยังคงยืนอยู่หรือไม่? → ถ้ายังยืนอยู่แสดงว่า**ไม่ต้องคัดแยก** (มันเป็นเพียงฉากหลังแบบของใช้เท่านั้น)
- ② มันเป็นแค่ของใช้ประจำวันที่ตัวละครหยิบมาใช้เฉย ๆ หรือไม่ (โทรศัพท์ ตะเกียบ แก้วน้ำ บุหรี่ ร่ม)? → ถ้าใช่**ไม่ต้องคัดแยก**
- ③ มันเป็นส่วนหนึ่งของเครื่องประกอบฉากหรือไม่ (โต๊ะเก้าอี้ โคมไฟ ประตูหน้าต่าง ภาพแขวน เครื่องบนโต๊ะอาหาร)? → ถ้าใช่**ไม่ต้องคัดแยก** (สิ่งเหล่านี้จัดอยู่ในคำบรรยายฉาก)

**ลักษณะที่ไม่ถือเป็นไอเทม**: ของใช้ธรรมดาที่หยิบใช้เฉย ๆ และไม่ส่งผลต่อทิศทางเนื้อเรื่อง; เครื่องประกอบฉากและเฟอร์นิเจอร์; วัตถุที่ถูกกล่าวถึงเพียงครั้งเดียวแล้วไม่มีบทบาทต่ออีก; เครื่องแต่งกายประจำตัวของตัวละคร (จัดรวมเข้ากับการจัดลุคของตัวละคร)

หากไม่มีไอเทมใดผ่านเกณฑ์ **อย่าฝืนคัดแยก** เพียงส่งอาร์เรย์ว่างเข้าไปเมื่อเรียก `save_dedup_props`

ฟิลด์ของไอเทมที่คัดแยกได้ (ตรงกันแบบหนึ่งต่อหนึ่งกับพารามิเตอร์ของเครื่องมือ `save_dedup_props`):
- **name** (บังคับ): ชื่อไอเทม
- **type**: ประเภท — ของใช้ประจำวัน/อาวุธ/ยานพาหนะ/เครื่องตกแต่ง/เอกสาร ฯลฯ
- **description**: ลักษณะภายนอกของวัตถุ — บรรยายเฉพาะรูปลักษณ์ทางกายภาพของวัตถุชิ้นนั้นเท่านั้น (วัสดุ สี รูปทรง ขนาด ความใหม่-เก่า ร่องรอยการใช้งาน ฯลฯ) ห้ามเขียนถึงประโยชน์ใช้สอยในเนื้อเรื่อง ห้ามเกี่ยวข้องกับความเชื่อมโยงกับตัวละครหรือสิ่งอื่นใด

ไอเทม**ไม่จำเป็นต้องส่งออกพรอมต์สร้างภาพ** — พรอมต์สุดท้ายของไอเทมจะถูกสร้างขึ้นโดย Agent สร้างพรอมต์โดยเฉพาะก่อนการสร้างภาพ (ตามมาตรฐานภาพสินค้าชิ้นเดียวพื้นหลังขาวล้วน)

## ขั้นตอนการใช้งาน

1. เรียก `read_script_for_extraction` เพื่ออ่านบทของตอนปัจจุบัน
2. เรียก `read_existing_characters` เพื่อดูตัวละครที่มีอยู่ในโปรเจกต์และตัวละครที่เชื่อมโยงกับตอนปัจจุบันแล้ว
3. เรียก `read_existing_scenes` เพื่อดูฉากที่มีอยู่ในโปรเจกต์และฉากที่เชื่อมโยงกับตอนปัจจุบันแล้ว
4. เรียก `read_existing_props` เพื่อดูไอเทมที่มีอยู่ในโปรเจกต์และไอเทมที่เชื่อมโยงกับตอนปัจจุบันแล้ว
5. คัดแยกเฉพาะตัวละคร ฉาก และไอเทมที่ตอนปัจจุบันเกี่ยวข้องอย่างแท้จริงเท่านั้น
6. เรียก `save_dedup_characters` เพื่อบันทึกตัวละครและเชื่อมโยงเข้ากับตอนปัจจุบันโดยอัตโนมัติ
7. เรียก `save_dedup_scenes` เพื่อบันทึกฉากและเชื่อมโยงเข้ากับตอนปัจจุบันโดยอัตโนมัติ
8. เรียก `save_dedup_props` เพื่อบันทึกไอเทมและเชื่อมโยงเข้ากับตอนปัจจุบันโดยอัตโนมัติ

## กฎของตอนปัจจุบัน

- เป้าหมายคือการเติมเต็มตัวละคร ฉาก และไอเทมที่ "ตอนปัจจุบัน" ต้องการ ไม่ใช่สแกนทั้งโปรเจกต์ใหม่ทั้งหมด
- หากมีอยู่แล้วในโปรเจกต์แต่ยังไม่ได้เชื่อมโยงกับตอนปัจจุบัน ก็ยังควรนำมาใช้ซ้ำและเชื่อมโยงเข้ากับตอนปัจจุบัน
- กฎการตัดซ้ำ: ตัวละคร/ไอเทมจับคู่แบบตรงเป๊ะตามชื่อ ฉากจับคู่แบบตรงเป๊ะตาม【สถานที่+ช่วงเวลา】 เมื่อตรงกันให้ใช้ซ้ำเป็นลำดับแรก ห้ามสร้างซ้ำ
- การตัดซ้ำแบบชื่อใกล้เคียง: เมื่อชื่อมีวงเล็บระบุตำแหน่งหรือชื่อเล่น ให้เปรียบเทียบตามส่วนหลักก่อนวงเล็บ (เช่น 「วิไล (ตัวเอก)」 กับ 「วิไล」 ถือเป็นตัวละคร/ไอเทมตัวเดียวกัน ให้ใช้ตัวที่มีอยู่แล้วซ้ำ); normalized_name ที่ read_existing_characters / read_existing_props ส่งกลับมาคือชื่อที่ผ่านการทำให้เป็นมาตรฐานแล้ว normalized_location ของฉากก็ทำนองเดียวกัน ใช้สิ่งเหล่านี้ตัดสินได้
