# พรอมต์วิดีโอ (ช่วงสตอรีบอร์ด → video_prompt)

จาก description (ที่ประกอบด้วยโครงสร้างช็อตย่อยแบบ【镜头N】และบทพูด/บทบรรยาย) / atmosphere / duration ของช่วงสตอรีบอร์ดหนึ่งช่วง ให้สร้าง `video_prompt` ที่ขับเคลื่อนการสร้างวิดีโอด้วย AI **หนึ่งช่วงสตอรีบอร์ด = วิดีโอหนึ่งคลิปความยาว 8-15 วินาที อนุญาตให้ตัดช็อตภายในได้**: ช่วงต่อช่วงเป็นช็อตต่างกันได้ (เปลี่ยนขนาดภาพ/มุมกล้อง/วัตถุถ่าย) เชื่อมกันด้วยการตัดแบบเฮิร์ดคัท; แต่**ตลอดทางห้ามข้ามฉาก** และห้ามฉากย้อนอดีต

## รูปแบบ

**บรรทัดแรกของ `video_prompt` คือหัวข้อข้อมูล**: เปิดด้วยการแนะนำว่าวิดีโอคลิปนี้มีตัวละครและฉากใดบ้าง จากนั้นจึงต่อด้วยช่วงเวลาแบ่งเป็นท่อน ๆ ตัวละครและฉากใช้การอ้างอิงด้วย @ เป็นหลักเสมอ (ตอนสร้างจะถูกแทนที่ด้วยเครื่องหมายภาพอ้างอิงที่ตรงกัน เพื่อให้โมเดลวิดีโอล็อกเป้า "ใคร" และ "ที่ไหน" ได้ก่อน)

```
ตัวละครที่ปรากฏ: @สมชาย, @มาลี; ฉาก: @ร้านกาแฟ.
0-3 วินาที: @ร้านกาแฟ ภาพระยะใกล้ กล้องมีจังหวะขึ้นลงเบา ๆ เหมือนการหายใจและดันเข้าหา@สมชายอย่างช้า ๆ เขาก้มมองโทรศัพท์ นิ้วเคาะโต๊ะซ้ำ ๆ สีหน้าแสดงความวิตกกังวล.
3-6 วินาที: ตัดไปยังภาพมุมกว้างหน้าประตู เสียงกระดิ่งประตูดังขึ้น @มาลีผลักประตูเดินเข้ามา พาลมเย็นกระชากพัดเข้ามาด้วย.
6-9 วินาที: ตัดกลับมาที่ภาพระยะกลาง @มาลีเดินเข้าไปหาสมชายด้วยรอยยิ้มแล้วนั่งลง สมชายพูดว่า: "มาซะทีนะ."
```

กฎของหัวข้อข้อมูล:
- ลิสต์เฉพาะตัวละครที่ปรากฏจริงในช่วงสตอรีบอร์ดนี้และฉากที่ผูกไว้ อย่าลิสต์ตัวที่ไม่ปรากฏ
- เมื่อมีไอเทมปรากฏอย่างเด่นชัด สามารถเพิ่มท้ายหัวข้อได้ (เช่น `; ไอเทม: @จดหมาย`)
- หัวข้ออยู่คนละบรรทัด จบด้วยจุด ตามด้วยช่วงเวลาแบ่งเป็นท่อน

แบ่งเป็นท่อนละ 3 วินาที แต่ละท่อนอยู่คนละบรรทัด คั่นด้วยการขึ้นบรรทัดใหม่ ช่วงเวลาต่อเนื่องเชื่อมกัน (ไม่ทับซ้อน ไม่มีช่องว่าง)

## การแปลงเทียบกับคำบรรยายสตอรีบอร์ด

`description` เป็นแหล่งเนื้อหาเพียงแหล่งเดียวของ video_prompt (ภาพ การกระทำ บทพูด บทบรรยาย ทั้งหมดอยู่ในนั้น) กฎการแปลง:

- `【镜头N】` แต่ละอันใน `description` แมปกับ **ท่อน 3 วินาทีต่อเนื่องกัน 1-2 ท่อน** ลำดับตรงกัน ไม่ตกหล่น ไม่รวมกัน ไม่เพิ่มช็อตย่อยใหม่
- บทพูด/บทบรรยายดึงจาก 「ชื่อตัวละครพูดว่า: "……"」「บรรยาย: ……」 ที่อยู่ภายใน `【镜头N】` ที่ตรงกัน แล้วจัดสรรไปยังท่อนที่ช็อตย่อยนั้นแมปไป; **ห้ามเขียนบทพูดใหม่นอกเหนือจาก description**
- ภาพและการกระทำใช้ `description` เป็นที่ยึด; `atmosphere` ใช้เพียงเติมคำบรรยายแสง โทนสี และบรรยากาศของแต่ละท่อน

## โครงสร้างภายในแต่ละท่อน

จัดเรียงเนื้อหาของแต่ละท่อนตามลำดับนี้ (ข้อที่ไม่มีเนื้อหาละได้ แต่การกระทำ/ภาพต้องมี):

**ช่วงเวลา ＋ การอ้างอิงฉากด้วย@ ＋ ขนาดภาพ/การเคลื่อนกล้อง ＋ การอ้างอิงตัวละครด้วย@＋การกระทำหลักของตัวละคร·สีหน้า ＋ บทพูด/บทบรรยาย ＋ บรรยากาศและแสง**

- **ท่อนแรกต้องสถาปนาพื้นที่**: ฉาก + ตำแหน่งกล้อง + ตำแหน่งและสถานะของตัวละครแต่ละคน ให้ผู้ชมรู้ภายในแวบเดียวว่าอยู่ที่ไหน มองใคร
- **การตัดช็อต**: ท่อนที่อยู่หลังจุดตัดเปิดด้วยคำเชื่อมอย่าง "ตัดไปที่/ตัดกลับมาที่" และบอกขนาดภาพกับวัตถุหลักใหม่; จุดตัดควรตรงแนวกับโครงสร้าง `【镜头N】` ใน `description` ของสตอรีบอร์ด
- **ขนาดภาพ/การเคลื่อนกล้อง (กฎแข็ง)**: ทุกท่อนต้องเขียนทั้ง **ขนาดภาพ** (ภาพใกล้/ภาพกลาง/ภาพกว้าง/ภาพปิด) และ **คำสั่งการเคลื่อนกล้อง**; การเคลื่อนกล้องต่อเนื่องภายในช็อตย่อยเดียว เปลี่ยนวิธีเคลื่อนกล้องได้หลังจุดตัด เขียนเป็น 「ขนาดภาพเริ่มต้น ＋ วิธีเคลื่อนไหว ＋ ความเร็ว/จังหวะ」 เช่น "ภาพกลางดันเข้าช้า ๆ ความเร็วคงที่จนถึงภาพปิดใบหน้า" "แพนข้างไปพร้อมตัวละคร พื้นหลังไหลเฉื่อยเป็นชั้น" ห้ามทิ้งท่อนทั้งท่อนไว้แค่ "กล้องนิ่ง" ล้วน ๆ โดยไร้ข้อมูลการเคลื่อนไหว — กล้องต้อง "ขยับ" ให้เป็น (การเลื่อนตำแหน่ง ซูม ตามติด จังหวะหายใจ ต่างนับรวมทั้งสิ้น) เพื่อเลี่ยงภาพนิ่งแบบสไลด์นำเสนอ (PPT) คลังคำการเคลื่อนกล้องดูได้จากหัวข้อ 「มาตรฐานการเคลื่อนกล้อง」 ด้านล่าง
- **การกระทำ**: หนึ่งท่อนมีการกระทำหลักหนึ่งอย่าง กริยาต้องเห็นภาพเป็นรูปธรรม (เดิน หันตัว เงยหน้า กำแน่น หยุดนิ่ง)
- **อารมณ์ทั้งหมดเปลี่ยนเป็นคำบรรยายที่มองเห็นได้**: ห้ามคำนามธรรมอย่าง "เขาเศร้ามาก/บรรยากาศตึงเครียด" ให้เขียนเป็น "เขาก้มหน้าลง นิ้วกำขอบแก้วแน่น การหายใจหนักขึ้น"
- **บทพูด/บทบรรยาย**: เขียนว่า 「ชื่อตัวละครพูดว่า: "บทพูด"」 บทบรรยายเขียนว่า 「บรรยาย: เนื้อหา」; บทพูดยาวที่พูดไม่ทันใน 3 วินาที ให้แยกออกเป็นหลายท่อน; ท่อนที่ไม่มีบทพูดเขียนเสียงบรรยากาศ/เสียงการกระทำได้ (เช่น "เครื่องจักรคำรามต่อเนื่องไม่หยุด")

## กฎการอ้างอิง

- `@ชื่อฉาก` — การอ้างอิงฉาก ชื่อต้องตรงกับสถานที่ในรายการฉากอย่างสมบูรณ์
- `@ชื่อตัวละคร` — การอ้างอิงตัวละคร ชื่อต้องตรงกับชื่อในรายการตัวละครอย่างสมบูรณ์
- `@ชื่อไอเทม` — การอ้างอิงไอเทม ชื่อต้องตรงกับชื่อในรายการไอเทมอย่างสมบูรณ์; อ้างอิงไอเทมเมื่อมันเห็นได้ชัดในเฟรม ถูกใช้งาน หรือโดนถ่ายภาพปิด
- ตอนสร้าง `@ชื่อ` จะถูกแทนที่ด้วยเครื่องหมายภาพอ้างอิงที่ตรงกันโดยอัตโนมัติ (เช่น `@สมชาย` → `@รูปที่1สมชาย`) ดังนั้นชื่อต้องตรงกันเป๊ะ ห้ามย่อหรือเติมสัญลักษณ์พิเศษ
- **ทุกท่อนต้องมีการอ้างอิง @ อย่างน้อยหนึ่งครั้งเพื่อยึดเฟรม**; ท่อนที่มีตัวละครปรากฏต้อง @ ตัวละครนั้น; อ้างอิงเฉพาะฉาก/ตัวละคร/ไอเทมที่ผูกกับช่วงสตอรีบอร์ดนี้แล้วเท่านั้น

## กฎเส้นเวลา

- จำนวนท่อน = duration ของช่วงสตอรีบอร์ด ÷ 3 วินาที (ปัดขึ้น) ช่วงเวลาของทุกท่อนบวกกันต้องเท่ากับความยาวรวมของช่วงพอดี
- จังหวะเนื้อหา: ท่อนแรกสถาปนา → ท่อนกลางขับเคลื่อนการกระทำ/ความขัดแย้ง → ท่อนสุดท้ายลงหลักที่ผลลัพธ์หรือจุดอารมณ์

## มาตรฐานการเคลื่อนกล้อง

ทุกช่วงเวลาต้องมีการเคลื่อนกล้อง เลือกจากคลังคำด้านล่างและให้สอดคล้องกับเจตนาการเคลื่อนกล้องในฟิลด์ `description`/`movement` ของสตอรีบอร์ด (description เขียนการเคลื่อนกล้องอะไร video_prompt ก็ขยายตามนั้น; เมื่อ description ไม่ได้เขียน ให้เลือกสิ่งที่เข้ากับภาพมากที่สุดเอง):

- **การเล่าเรื่องพื้นฐาน**: ดันเข้าอย่างช้า (ภาพกลาง→ภาพปิด ความเร็วคงที่ พื้นหลังเบลอไล่ระดับ) ถอยออกเผยภาพ (ภาพปิด→ภาพกว้าง เร็วก่อนช้าหลัง) แพนข้างตามติด (เคลื่อนไปพร้อมวัตถุหลัก พื้นหลังไหลเฉื่อยเป็นชั้น) ยกกล้องขึ้น-ลงมองภาพรวม (ไต่ขึ้น/ดิ่งลงในแนวตั้งเผยพื้นที่) โคจรเป็นวงโค้ง (โคจรรอบตัวละคร 90-180 องศา) เดินมุมมองบุคคลที่หนึ่ง (ระดับสายตา เอื้อนขึ้นลงเบา ๆ ดั่งลมหายใจ)
- **อารมณ์และบรรยากาศ**: ถือกล้องหอบเบา ๆ (สั่นเบา ๆ รุนแรงขึ้นหลังการเคลื่อนไหว) มุมมองแอบดู (ช่องประตู/ช่องหน้าต่างบังเป็นฉากหน้า) ชีพจรเต้นตามจังหวะใจ (ดัน-ถอยสอดประสานจังหวะอารมณ์ สงบดันเข้าช้า/ตึงเครียดดันเข้าเร็ว) เคลื่อนตามจังหวะหายใจ (ดันเข้าตอนหายใจเข้า ถอยออกช้า ตอนหายใจออก)
- **รายละเอียดจิตใจ**: โฟกัสการจ้องมอง (ดันเข้าหาสิ่งที่ถูกจ้องอย่างช้า ๆ เลื่อนจุดโฟกัส) สั่นเทาด้วยความหวาดกลัว (สั่นพริ้วเล็ก ๆ ไม่เป็นจังหวะ) โคจรอย่างอ่อนหวาน (โคจรช้ามุมเล็ก จุดโฟกัสล็อกที่ใบหน้า) ไล่ตามความเร็วสูง (ตามแนบแน่นพร้อมความเบลอจากความเร็ว) สลับซองไปมาในฉากต่อสู้ (ตัดไปมาอย่างรวดเร็วระหว่างคู่ต่อสู้) พุ่งดิ่งจากท้องฟ้า (ดิ่งลงจากที่สูง ตอนลงพื้นสั่นนิดหนึ่ง)
- **การต่อสู้ความเร็วสูง**: ทำเฉพาะเมื่อ `description` ของสตอรีบอร์ดเขียนการเคลื่อนกล้องต่อสู้ไว้ชัดเจน ให้ขยายตาม description ต้นฉบับเป๊ะ (ตำแหน่งกล้อง ความเร็ว ตัวเลข ต้องไม่ขาดสักอย่าง): ดันกล้องระดับต่ำอย่างรวดเร็ว แนบพื้นตามติด เงยกล้องขึ้นอย่างรวดเร็ว ตามติดแนบแน่นสุดขีด ดันกล้องย้อนทิศพร้อมสลับจุดโฟกัส ถอยออกอย่างรวดเร็วพร้อมหางทางเคลื่อนที่ ความเบลอความเร็วสูง 0.15 วินาทีที่วินาทีปะทะ สั่นสะเทือน shake 0.3 วินาที
- **มุมมองพิเศษ**: มุมต่ำมองขึ้นสุด กล้องเอียงแบบดัตช์แองเกิล ช็อตเหนือบ่า มุมมองบุคคลที่หนึ่ง
- **จังหวะและทรานซิชัน**: เหวี่ยงกล้องเร็ว (ทิศทางเหวี่ยงตรงกับทิศการเคลื่อนไหวของท่อนถัดไป) ทรานซิชันผ่านสิ่งบัง (วัตถุฉากหน้ากวาดผ่านบังภาพแล้วตัดช็อตในชั่วขณะ) หยุดกึกค้างเฟรม (ชะลอลงจนนิ่งค้าง จำกัดเฉพาะท่อนระเบิดจุดไคลแมกซ์)

ข้อกำหนดการเขียน:
- คำสั่งการเคลื่อนกล้องต้องผูกกับขนาดภาพและความเร็วไปพร้อมกัน: "จากภาพกว้างดันเข้าอย่างช้า ๆ จนถึงภาพกลาง" ห้ามเขียนแค่ "ดันกล้อง" ลอย ๆ
- คำบอกความเร็วต้องเป็นรูปธรรม: ความเร็วคงที่/อย่างช้า/อย่างรวดเร็ว/เร็วก่อนช้าหลัง/ช้าสู่เร็ว
- หนึ่งท่อนหนึ่งการเคลื่อนกล้อง; ต่อเนื่องภายในท่อน เปลี่ยนเฉพาะจุดตัดช็อต
- บูลเล็ตไทม์/ภาพปิดแบบสโลว์โมชัน/มุมปลา/ภาพมินิเจอร์ เป็นเทคนิคเก็บรายละเอียดแบบประดับจุด ใช้เฉพาะเมื่อ `description` ของสตอรีบอร์ดเขียนไว้ชัดเจนเท่านั้น หนึ่งตอนมากที่สุด 1-2 จุด
- กล้องถือสั่นและจังหวะหายใจถือเป็น "ไมโครมูฟเมนต์" ใช้ทดแทนการเคลื่อนที่สมบูรณ์นิ่งในท่อนที่ตั้งใจจะเขียนกล้องนิ่งได้

## สิ่งที่ห้าม

- การข้ามฉาก ฉากย้อนอดีต (หนึ่งท่อนเกิดขึ้นในฉากเดียวเท่านั้น)
- อ้างอิงฉาก/ตัวละครที่อยู่นอกรายการ
- คำบรรยายจิตใจนามธรรม อุปมาเชิงวรรณศิลป์ (โมเดลรู้จักเฉพาะภาพที่มองเห็นได้)
- การแสดงเกินจริง: ห้ามเขียนกรีดร้อง ตะโกนลั่น โวยวายดังลั่น ร้องไห้โฮ; ความตกใจให้เขียนเป็นปฏิกิริยายิบย่อย (แข็งค้าง รูม่านตาหด เอ่ออากาศเข้าเสียงเดียว ถอยไปครึ่งก้าว) บทพูดใช้น้ำเสียงและระดับเสียงแบบชีวิตประจำวัน (เมื่อเนื้อเรื่องสุดขีดจริง ๆ ต้องระเบิด ให้เขียนกำกับไว้ชัดเจนในท่อนนั้นว่า 「ระเบิดอารมณ์」 แทนที่)
- สโลว์โมชันและการขัดถ่ายด้วยความนิ่ง: ค่าเริ่มต้นคือไม่ใช้สโลว์โมชัน ไม่เขียนการจ้องมองนิ่งยาว; ข้อยกเว้น: ช็อตย่อยจุดระเบิดที่ `description` ของสตอรีบอร์ดเขียนบูลเล็ตไทม์/ภาพปิดแบบสโลว์โมชัน/หยุดกึกค้างเฟรมไว้ชัดเจน ใช้ได้ตาม description แต่ละท่อนยังต้องมีการเคลื่อนกล้องหรือการไต่ความเข้มของการกระทำที่มองเห็นได้ ไม่อนุญาตให้เป็น "ช็อตนิ่งล้วน"
- ภาษาไม่ตรงกับคำสั่งภาษาของเซสชัน

## การบันทึก

เรียก `update_storyboard` อัปเดตเฉพาะฟิลด์ `video_prompt` ของช่วงสตอรีบอร์ดนี้ ห้ามแก้ฟิลด์อื่น ห้ามแบ่งส่วนใหม่ทั้งตอน แพลตฟอร์มจะเพิ่มส่วนป้องกันการแสดงและจังหวะโดยอัตโนมัติตอนยื่นคำขอสร้างจริง ไม่จำเป็นต้องเขียนข้อกำหนดเหล่านั้นซ้ำในพรอมต์
