# 视频提示词（分镜段落 → video_prompt）

根据单个分镜段落的 description（含【镜头N】子镜头结构与台词/旁白）/ atmosphere / duration，生成驱动 AI 视频生成的 `video_prompt`。**一个分镜段落 = 一段 8-15 秒的视频，内部允许切镜**：段与段之间可以是不同镜头（换景别/角度/对象），用硬切衔接；但**全程不跨场景**、不闪回。

## 格式

`video_prompt` 的**第一行是信息头**：先介绍这条视频有哪些人物和场景，然后再接时间分段。人物、场景一律用 @ 引用（生成时会替换为对应参考图片标记，让视频模型先对上"谁"和"在哪"）。

```
出场人物：@小明、@小红；场景：@咖啡厅。
0-3秒：@咖啡厅，近景，镜头带着呼吸感轻微起伏并向@小明缓缓推近，他低头看手机，手指反复敲桌面，表情焦虑。
3-6秒：切到门口全景，门铃响，@小红推门走入，带进一阵冷风。
6-9秒：切回中景，@小红微笑着走向小明坐下，小明说：「你终于来了。」
```

信息头规则：
- 只列该分镜段落实际出场的人物和绑定的场景，不要列没出场的
- 有明显道具出场时可在信息头追加（如 `；道具：@信件`）
- 信息头独立一行，以句号结尾，之后是时间分段

按 3 秒为一段，每段单独一行、用换行分隔，时间范围连续衔接（无重叠、无空缺）。

## 与分镜描述的映射

`description` 是 video_prompt 的唯一内容来源（画面、动作、台词、旁白都在其中），转换规则：

- `description` 的每个 `【镜头N】` 映射为 **1-2 个连续的 3 秒段**，顺序一致、不遗漏、不合并、不新增子镜头
- 台词/旁白从对应 `【镜头N】` 内的「角色名说：「…」」「旁白：…」提取，分配到该子镜头映射的段；**不要创作 description 之外的新台词**
- 画面动作以 `description` 为准；`atmosphere` 只用于补各段的光线、色调与氛围描写

## 段内结构

每一段按此顺序组织内容（可省略无内容的项，但动作/画面必须有）：

**时间范围 ＋ 场景@引用 ＋ 景别/运镜 ＋ 角色@引用＋主体动作·表情 ＋ 对白/旁白 ＋ 氛围光线**

- **第一段必须建立空间**：场景 + 机位 + 角色的位置与状态，让观众一眼知道在哪、看谁
- **切镜**：切镜后的段开头用"切到/切回"等衔接词，并重新交代景别与主体；切镜点应对齐分镜 `description` 中的 `【镜头N】` 结构
- **景别/运镜（硬规则）**：每段必须同时写明**景别**（近景/中景/全景/特写）与**镜头运动指令**；单个子镜头内运镜连续，切镜后可更换运镜方式。运镜写法＝「起始景别 ＋ 运动方式 ＋ 速度/节奏」，如"中景匀速缓推至面部特写"、"与角色同步横移，背景视差流动"。禁止整段只写"固定镜头"而无运动信息——镜头必须"动"起来（位移、变焦、跟随、呼吸感起伏均可），避免 PPT 式静止画面。运镜词库见下方「运镜规范」
- **动作**：每段一个主动作，动词具体可见（走、转身、抬头、攥紧、停顿）
- **情绪全部转为可见描写**：不要"他很伤心/气氛紧张"这类抽象词，写成"他低下头、手指攥紧杯沿、呼吸变重"
- **对白/旁白**：写「角色名说：「台词」」，旁白写「旁白：内容」；3 秒念不完的长台词拆到多段；无对白的段可写环境音/动作音（如"机器持续轰鸣"）

## 引用规则

- `@场景名` — 场景引用，名字必须与场景列表中的地点完全一致
- `@角色名` — 角色引用，名字必须与角色列表中的名字完全一致
- `@道具名` — 道具引用，名字必须与道具列表中的名字完全一致；道具在画面中明显可见、被使用或特写时引用
- 生成时会自动把 `@名字` 替换为对应参考图片标记（如 `@小明` → `@图片1小明`），因此名字必须精确匹配，不要缩写或加额外符号
- **每段至少一个 @ 引用锚定画面**；角色出场的段必须 @ 该角色；只引用该分镜段落已绑定的场景/角色/道具

## 时间轴规则

- 段数 = 分镜段落 duration ÷ 3 秒（向上取整），各段时间范围相加必须等于段落总时长
- 内容节奏：第一段建立 → 中段推进动作/冲突 → 末段落到结果或情绪点

## 运镜规范

每个时间段都要有镜头运动，从以下词库选择并与分镜 `description`/`movement` 字段的运镜意图保持一致（description 写了什么运镜，video_prompt 就展开什么运镜；description 未写时按画面内容自行选择最贴合的）：

- **基础叙事**：缓推（中景→特写，匀速，背景渐虚化）、拉远揭示（特写→全景，先快后慢）、横移跟随（与人物同步移动，背景视差流动）、升降俯瞰（垂直上升/下降展现空间）、弧形环绕（以角色为中心 90-180 度环绕）、第一人称行走（视线高度，呼吸般轻微起伏）
- **情绪氛围**：手持喘息（轻微晃动，运动后加剧）、窥视视角（门缝/窗隙前景遮挡）、心跳脉冲（推拉与情绪节奏同步，平静缓推/紧张快推）、呼吸贴合（吸气微推、呼气缓拉）
- **心理细节**：凝视聚焦（缓缓推近被凝视物，焦点转移）、颤抖恐惧（不规则细微颤动）、温柔环绕（慢速小角度环绕，焦点锁定面部）、疾速追尾（紧随移动目标，动态模糊）、打斗穿梭（快速在对战双方间切换）、飞跃俯冲（高空俯冲，落地微震）
- **高速打斗**：仅当分镜 `description` 明确写了打斗运镜时按 description 原样展开（机位、速度、数值一个都不能丢）：低位急速推镜、贴地跟随、急速上摇、极限贴近跟拍、反向推镜切焦点、急速拉远拖尾、命中瞬间 0.15 秒高速模糊化、震击 shake 0.3 秒
- **特殊视角**：极低仰拍、荷兰角倾斜、过肩近景、主观视角
- **节奏转场**：快速甩镜（甩动方向与下一段运动方向一致）、遮挡转场（前景物扫过遮挡瞬间切镜）、急停定帧（减速至静止定格，限爆点段）

写法要求：
- 运镜指令与景别、速度绑定出现："从全景缓慢推近至中景"，不要只写"推镜"
- 速度副词具体：匀速/缓慢/急速/先快后慢/由慢到快
- 一段一运镜；段内运镜连续，切镜点才更换
- 子弹时间/慢动作特写/鱼眼/微缩景观为点睛特技，仅当分镜 `description` 明确写了时才使用，一集最多 1-2 处
- 手持晃动、呼吸起伏属于"微运动"，可用于原本想写固定镜头的段落，替代完全静止

## 禁止事项

- 跨场景切换、闪回（一个段落只发生在一个场景内）
- 引用列表之外的场景/角色名
- 抽象心理描写、文学化比喻（模型只认可见画面）
- 过度表演：不写尖叫、嘶吼、大呼小叫、放声痛哭；受惊写成微反应（僵住、瞳孔一缩、倒吸气、后退半步），对白用日常语气与日常音量（极端剧情确需爆发时，在该段显式写「情绪爆发」覆盖）
- 慢动作与静止拖延：默认不使用慢动作、不写长时间静止凝视；例外：分镜 `description` 明确写有子弹时间/慢动作特写/急停定帧的爆点子镜头，可按 description 使用。每段仍需有可见的镜头运动或动作推进，不允许"纯静止镜头"
- 语言与会话语言指令不符

## 保存

调用 `update_storyboard` 仅更新该分镜段落的 `video_prompt` 字段，不要改动其他字段，不要重新拆分整集。平台会在实际生成请求时自动追加表演与节奏守卫，提示词内无需重复书写这些要求。
