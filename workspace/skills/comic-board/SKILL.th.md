# คู่มือการดัดแปลงสตอรีบอร์ดการ์ตูน

## หลักการแบ่งช่องโดยรวม

- แต่ละบทมี 8-16 ช่อง; บทสั้นใช้ค่าต่ำสุด บทที่ความขัดแย้งรุนแรงใช้ค่าสูงสุด
- จังหวะการแบ่งช่องต้องเชื่อฟังเนื้อเรื่อง: ฮุกเปิดเรื่อง 1-2 ช่อง การขับเคลื่อนความขัดแย้ง 4-8 ช่อง คลิฟแฮนเกอร์ท้ายเรื่อง 1-2 ช่อง
- หนึ่งช่อง = หนึ่งหน่วยภาพที่เป็นอิสระ: หนึ่งการกระทำ หนึ่งปฏิกิริยา หรือหนึ่งการสถาปนาฉาก ห้ามยัดสองกาลสถานเข้าไว้ในช่องเดียว
- ช่องที่อยู่ติดกันต้องมีขนาดภาพเปลี่ยนไป: การใช้ขนาดภาพเดียวกันติดต่อกัน 3 ช่องถือเป็นข้อห้ามร้ายแรงที่สุด

## ข้อกำหนดฟิลด์ของแต่ละช่อง

- description (คำบรรยายภาพ): ตัวละคร + การกระทำ + สีหน้า + องค์ประกอบฉากหลัง บรรยายให้ชัดเจนในประโยคเดียวว่า "ใครกำลังทำอะไร"; ลุคของตัวละครต้องสอดคล้องกับโลกทัศน์/ยุคสมัยของเรื่องเสมอ
- dialogue: ใส่เฉพาะบทพูดหรือคำบรรยายที่จำเป็นต้องปรากฏในช่องนี้ ไม่เกินหนึ่งประโยค; ต้องเป็นถ้อยคำจากต้นฉบับบท อย่าแต่งบทพูดขึ้นใหม่; ช่องที่ไม่มีบทพูดเป็นเครื่องมือจัดจังหวะที่ใช้ได้ตามปกติ
- narration (บทบรรยายแบบหนังสือภาพต่อเนื่อง, 40–120 ตัวอักษร, ต้องใส่ทุกช่อง): ร้อยแก้วแบบเล่าเรื่องบุรุษที่สาม ทำหน้าที่ขับเคลื่อนเรื่องราว — เกิดอะไรขึ้น ปฏิกิริยา/จิตใจของตัวละคร ฮุกหรือจุดพลิกผัน; รวมบทพูดเข้ากับการเล่า (เช่น 「ใครสักคนตะโกนว่า: ……」); เมื่ออ่านบทบรรยายของทุกช่องเรียงต่อกันต้องได้เรื่องราวที่สมบูรณ์ ห้ามใช้เพียงเศษคำบรรยายบรรยากาศ
- composition (องค์ประกอบภาพและมุมกล้อง): ขนาดภาพ (ภาพมุมไกล/ภาพมุมกว้าง/ภาพระยะกลาง/ภาพระยะใกล้/ภาพปิด) + มุมกล้อง (ระดับสายตา/มองลง/มองขึ้น) + เจตนาการวางองค์ประกอบ (เช่น 「มุมมองเหนือบ่า」 「ปล่อยที่ว่างไว้มากเพื่อกดอารมณ์」)
- image_prompt (พรอมต์สร้างภาพ, ภาษาอังกฤษ): ตัวหลัก + การกระทำ + สภาพแวดล้อม + แสง + องค์ประกอบภาพ เป็นย่อหน้าเดียวต่อเนื่อง 30-60 คำ; **ห้ามใส่คำบอกสไตล์** (สไตล์ภาพจะถูกฉีดเข้ามาโดยระบบอย่างเป็นเอกภาพ); ห้ามใส่ข้อความบทพูดลงในภาพ; ข้อจำกัดด้านคุณภาพ (นิ้วมือห้านิ้ว/นิ้วเท้าห้านิ้ว/แขนขาครบสมบูรณ์/ตัวละครคนเดียวไม่ซ้อนเงา/สีหน้ายับยั้งชั่งใจ/ภาพไม่มีข้อความหรือลายน้ำ) ระบบจะเพิ่มเข้าให้โดยรวมตอนสร้างภาพ ไม่จำเป็นต้องเขียนลงไป — แต่การบรรยายท่าทางควรหลีกเลี่ยงท่ามือที่ซับซ้อน ใช้ท่าทางร่างกายและแววตาแสดงอารมณ์ ห้ามใช้คำอย่าง 「ตะโกนลั่น/ตะโกนดังลั่น」 (หากจำเป็นต้องระเบิดจริง ให้เขียนกำกับไว้ชัดเจนว่า 「ระเบิดอารมณ์」) และในหนึ่งช่องไม่ควรมีตัวละครหลายคนซ้อนทับกันมากเกินไป

## เทคนิคการเล่าเรื่องด้วยภาพ

- ใช้ภาพปิดกับจุดพลิกผันของอารมณ์สำคัญ; ใช้ภาพมุมกว้างเพื่อกำหนดความสัมพันธ์เชิงพื้นที่; แต่ละบทต้องมีภาพมุมไกลอย่างน้อย 1 ภาพเพื่อสร้างความรู้สึกเรื่องพื้นที่
- สำหรับบทที่มีบทสนทนาเยอะ: แยกบทพูดยาวออกเป็นหลายช่อง คั่นด้วยช่องแสดงปฏิกิริยาสีหน้า หลีกเลี่ยง 「กำแพงช่องสนทนา」
- ช่องคลิฟแฮนเกอร์ท้ายเรื่อง = ภาพแห่งความลุ้นสูงสุด (หยุดภาพนิ่งไว้ชั่วขณะก่อนการเปลี่ยนแปลงจะเกิดขึ้น) พร้อมบทพูดหรือบทบรรยายฮุกหนึ่งประโยค
- สลับช่องเงียบกับช่องระเบิด: ช่องแอ็กชันต่อเนื่องกันไม่เกิน 3 ช่อง ให้แทรกช่องปฏิกิริยาหรือช่องภาพเปล่าไว้พักหายใจกลางลึก

## การเลือกตัดสินในการดัดแปลง

- คำบรรยายจิตใจในบท → เปลี่ยนเป็นใบ้ความผ่านสีหน้า/ท่าทาง/องค์ประกอบภาพ ห้ามวาดตัวหนังสือลงในภาพโดยตรง
- เนื้อหาช่วงเปลี่ยนผ่านในบท → ใช้ 1 ช่องภาพเปล่าหรือช่องทรานซิชันพาผ่านไป เล่าเรื่องได้เทียบเท่ากัน
- คงความขัดแย้งและการพลิกปมที่รุนแรงที่สุดไว้ ยอมสละรายละเอียดปลีกย่อย: ทุกช่องต้อง 「คู่ควรแก่การดู」
