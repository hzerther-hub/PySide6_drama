# 만화 스토리보드 개편 가이드

## 칸의 기본 원칙

- 매 화 8-16칸; 짧은 화는 하한, 강한 갈등의 화는 상한
- 칸 리듬은 이야기를 따릅니다: 도입 훅 1-2칸, 갈등 전개 4-8칸, 결말 클리프행어 1-2칸
- 한 칸에는 하나의 독립된 화면 단위: 하나의 동작, 하나의 반응, 하나의 장면 확립. 두 시공간을 한 칸에 넣지 않습니다
- 인접 칸은 샷 크기를 바꿉니다: 같은 샷 크기 3연속은 금물

## 칸별 필드 규범

- description(화면 묘사): 인물 + 동작 + 표정 + 배경 요소, 「누가 무엇을 하는가」를 한 문장으로. 인물 의상은 책의 세계관·시대와 일치시킵니다
- dialogue: 이 칸에 꼭 필요한 대사나 내레이션만, 한 줄 이내. 대사는 대본 원문에서 가져가고 새로 쓰지 않습니다. 대사 없는 칸은 정당한 리듬 수법입니다
- composition(카메라와 구도): 샷 크기(원경/전경/중경/근경/클로즈업) + 앵글(아이레벨/앵글/로우) + 구도 의도(예: 「어깨 너머 시점」「여백으로 감정 압축」)
- image_prompt(이미지 생성 프롬프트, 영어): 피사체 + 동작 + 환경 + 조명 + 구도, 30-60 단어의 연결된 한 문단. **스타일 단어를 쓰지 않습니다**(화풍은 시스템이 일괄 주입). 대사 텍스트를 넣지 않습니다

## 비주얼 스토리텔링 기법

- 감정의 전환점은 클로즈업; 공간 관계는 전경으로; 매 화 최소 1칸의 원경으로 공간감을 세웁니다
- 대사가 많은 대본: 긴 대사는 여러 칸으로 나누고 표정 반응 칸을 끼워 넣어 「대화 칸의 벽」을 피합니다
- 결말 클리프행어 칸 = 최대 서스펜스 화면(변화가 일어나기 직전의 정지 화면) + 훅이 되는 한 줄
- 조용한 칸과 폭발적인 칸을 교차: 연속 액션 칸은 3칸 이내, 사이에 반응 칸이나 빈 장면 칸으로 숨을 쉬게 합니다

## 개편의 취사선택

- 대본의 심리 묘사 → 표정/동작/구도의 암시로 변환하고 텍스트를 직접 그리지 않습니다
- 과도적 내용 → 칸 하나의 빈 장면이나 전환 칸으로 같은 서사를 처리합니다
- 가장 강한 갈등과 반전은 남기고 세부는 희생합니다: 모든 칸이 「볼 가치」가 있어야 합니다
