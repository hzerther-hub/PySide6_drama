# Guide d'adaptation en storyboard BD

## Règles générales de découpage en cases

- 8-16 cases par chapitre ; les chapitres courts visent le bas de la fourchette, les chapitres à fort conflit le haut
- Le rythme des cases suit l'intrigue : accroche d'ouverture 1-2 cases, montée du conflit 4-8 cases, cliffhanger final 1-2 cases
- Une unité visuelle distincte par case : une action, une réaction ou une installation de décor — jamais deux espaces-temps comprimés dans une même case
- Les cases adjacentes doivent varier d'échelle de plan : trois cases consécutives à la même échelle de plan sont un péché capital

## Règles des champs de chaque case

- description (description visuelle) : personnage + action + expression + éléments de décor, une phrase claire indiquant « qui fait quoi » ; le style des personnages doit rester cohérent avec l'univers / l'époque du livre
- dialogue : uniquement la réplique ou la narration devant impérativement apparaître dans cette case, une phrase maximum ; réplique tirée mot pour mot du scénario, n'en écrivez jamais de nouvelles ; une case sans réplique est un procédé de rythme parfaitement légitime
- narration (narration façon livre d'images, 40–120 caractères, obligatoire pour chaque case) : prose narrative à la troisième personne qui fait avancer l'histoire — ce qui se passe, réactions / état d'esprit des personnages, accroche ou retournement ; les répliques sont fondues dans le récit (« Untel tonna : … ») ; lues de bout en bout, les narrations de tout l'épisode doivent former une histoire complète — les fragments d'ambiance sans substance narrative sont interdits
- composition (cadrage caméra) : échelle de plan (plan très large / d'ensemble / moyen / rapproché / gros plan) + angle (hauteur d'œil / plongée / contre-plongée) + intention de composition (ex. « vue par-dessus l'épaule », « grand espace négatif pour porter l'émotion »)
- image_prompt (prompt de génération d'image, en anglais) : sujet + action + environnement + lumière + composition, en un seul paragraphe cohérent de 30-60 mots ; **aucun mot de style** (le style graphique est injecté de façon uniforme par le système) ; aucun texte de dialogue dans l'image ; les contraintes de qualité (cinq doigts et cinq orteils / membres complets / personnage unique sans dédoublement / expressions retenues / aucun texte ni filigrane dans l'image) sont ajoutées uniformément par le système au moment de la génération — inutile de les écrire ; en revanche, évitez les gestes complexes dans la description des actions, exprimez les émotions par la posture et le regard, n'employez pas de termes du type « hurler / crier » (si une explosion émotionnelle est réellement nécessaire, écrivez explicitement « explosion émotionnelle »), et évitez de superposer trop de personnages dans une même case

## Techniques de narration visuelle

- Gros plan pour les tournants émotionnels clés ; plan d'ensemble pour poser les relations spatiales ; au moins 1 plan très large par chapitre pour installer la sensation d'espace
- Scénarios très dialogués : répartissez les longues répliques sur plusieurs cases, entrecoupez de cases de réactions expressives — évitez le « mur de cases de dialogue »
- La case de cliffhanger finale = l'image de suspense maximal (arrêt sur image à l'instant qui précède le changement), accompagnée d'une réplique ou d'une narration d'accroche
- Alternez cases calmes et cases explosives : pas plus de 3 cases d'action consécutives, en insérant entre elles une case de réaction ou une case de plan d'atmosphère pour laisser respirer

## Choix d'adaptation

- Les descriptions psychologiques du scénario → à convertir en indices d'expression / d'action / de composition, jamais dessinées sous forme de texte
- Les passages transitoires du scénario → à évacuer avec 1 case de plan d'atmosphère ou une case de transition, en équivalence narrative
- Conservez les conflits et les retournements les plus forts, sacrifiez les menus détails : chaque case doit « mériter le regard »
