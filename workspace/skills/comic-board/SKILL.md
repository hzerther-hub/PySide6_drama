# 漫画分镜改编指南

## 分格总则

- 每章 8-16 格；短章取下限，强冲突章取上限
- 分格节奏服从剧情：开场钩子 1-2 格、冲突推进 4-8 格、结尾卡点 1-2 格
- 一格一个独立画面单元：一个动作、一个反应或一个场景建立，不把两个时空塞进一格
- 相邻格景别必须有变化：连续 3 格同景别是大忌

## 每格字段规范

- description（画面描述）：人物 + 动作 + 表情 + 背景要素，一句话写清「谁在做什么」；人物造型必须与本书世界观/所处时代一致
- dialogue：只放该格必须出现的台词或旁白，一句以内；台词取自剧本原文，不要新写；无台词格是正常节奏手段
- narration（小人书旁白，40–120 字，每格必填）：第三人称叙事散文，推进故事——发生了什么、人物反应/心理、钩子或转折；台词并入叙述（「某某喝道：……」）；整话旁白连读应是完整故事，禁止氛围碎片
- composition（镜头构图）：景别（远/全/中/近/特写）+ 角度（平视/俯/仰）+ 构图意图（如「过肩视点」「大留白压情绪」）
- image_prompt（出图提示词，英文）：主体 + 动作 + 环境 + 光线 + 构图，单段连贯 30-60 词；**不写风格词**（画风由系统统一注入）；不写对白文字入图；质量约束（五指五趾/四肢完整/单人不重影/表情克制/画面无文字水印）由系统出图时统一追加，无需写入——但动作描写避免复杂手势，情绪用肢体姿态与眼神表达，不写嘶吼/大喊类词（确需爆发时显式写「情绪爆发」），单格人物不宜过多重叠

## 视觉叙事技巧

- 关键情绪转折用特写；空间关系交代用全景；每章至少 1 个大远景建立空间感
- 对白多的剧本：把长对白拆到多格，用表情反应格切分，避免「对话格子墙」
- 结尾卡点格 = 最大悬念画面（定格在变化发生前一瞬），配一句钩子台词或旁白
- 安静格与爆发格交替：连续动作格不超过 3 格，中间插反应格或空镜格喘息

## 改编取舍

- 剧本的心理描写 → 转化为表情/动作/构图暗示，不直接画文字
- 剧本的过渡性内容 → 用 1 格空镜或转场格带过，等价叙事
- 保留最强冲突与反转，牺牲细枝末节：每格都必须「值得看」
